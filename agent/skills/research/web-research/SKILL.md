# Web research with citations

1. Break the question into 2–4 search queries (different angles, include the year for current topics).
2. `web_search` each; pick 3–6 credible, primary sources (official docs, papers, reputable outlets).
3. `web_extract` those pages (several URLs in one call). Skim for the specific facts needed.
4. Cross-check key numbers/claims across at least two sources; note disagreements.
5. Answer: direct answer first, then supporting points, each with a [n] citation; list sources (title + URL) at the end. State uncertainty and dates.
6. Never cite a page you didn't open.
